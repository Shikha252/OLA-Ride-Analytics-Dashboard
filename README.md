
# 🚖 OLA Ride Analytics DashBoard | Excel, MySQL & Power BI

An end-to-end **Data Analytics project** focused on exploring OLA ride-booking data using Excel, MySQL/SQL, and Power BI. The project analyzes ride trends, booking outcomes, vehicle performance, revenue, cancellations, ride distances, and customer and driver ratings to uncover meaningful business insights.

## 📊 Dataset Overview

The project uses OLA ride-booking data with the following details:

- **103,024** booking records
- **20** columns
- **7** vehicle types
- **Date Range:** 1 July 2024 – 31 July 2024

**Dataset:** [Download bookings.xlsx](https://github.com/user-attachments/files/32450361/bookings.xlsx)

## 🧠 SQL Analysis

Performed SQL analysis to answer 10 key business questions:

1. Retrieve all successful bookings.
2. Calculate average ride distance for each vehicle type.
3. Identify the number of customer-cancelled rides.
4. Find the top 5 customers based on ride bookings.
5. Count driver cancellations due to personal or car-related issues.
6. Find maximum and minimum driver ratings for Prime Sedan.
7. Retrieve rides paid through UPI.
8. Calculate average customer ratings by vehicle type.
9. Calculate total booking value of successful rides.
10. Identify incomplete rides along with their reasons.

**SQL File:** [ola SQL.sql](https://github.com/user-attachments/files/32450837/ola.SQL.sql)

## 📈 Power BI Dashboard

Developed an interactive Power BI dashboard with five major analytical sections:

- **Overall Analysis:** Ride volume trends and booking status breakdown.
- **Vehicle Type Analysis:** Performance and ride metrics across different vehicle categories.
- **Revenue Analysis:** Revenue by payment method, top 5 customers by booking value, and daily ride distance distribution.
- **Cancellation Analysis:** Customer and driver cancellation reasons.
- **Ratings Analysis:** Customer and driver rating trends.

The dashboard transforms raw booking data into meaningful visual insights to understand ride performance and business operations.

## ▶️ How to Use

### 1. Excel

Download and open the dataset:

[bookings.xlsx](https://github.com/user-attachments/files/32450361/bookings.xlsx)

### 2. MySQL

Create a database and import the dataset into a table named `bookings`.

Execute the following command:

```sql
USE ola;
```

Open and execute the SQL analysis file:

[ola SQL.sql](https://github.com/user-attachments/files/32450837/ola.SQL.sql)

### 3. Power BI

Open the `OLA.pbix` file in Microsoft Power BI Desktop.

If prompted, reconnect the data source according to your local file or database configuration.
